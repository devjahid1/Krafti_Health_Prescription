# MediLink RX – Doctor Portal

A modern and responsive doctor portal designed to simplify healthcare management and improve the digital experience for healthcare professionals.

## Overview

MediLink RX is the doctor-facing portal of the MediLink healthcare platform. It is designed to provide doctors with a centralized interface for managing appointments, patients, digital prescriptions, templates, reports, and other healthcare-related activities.

The portal is currently under development.

## Features

Planned features include:

- **Dashboard** – Overview of doctor activities and essential information.
- **Appointment Management** – Manage and track patient appointments.
- **Patient Management** – Access and manage patient information.
- **Digital Prescriptions** – Create and manage electronic prescriptions.
- **Prescription Templates** – Save and reuse prescription templates.
- **Reports** – View healthcare-related reports.
- **Settings** – Manage account and portal preferences.
- **Help & Support** – Access assistance and support resources.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd your-project-folder
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite in your browser.
